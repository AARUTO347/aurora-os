# AURORA OS branding

**MADE BY AARUTO**

| File | Use |
|---|---|
| `logo-mark.svg` | Square emblem, 1024×1024. Repository avatar, application icon, boot splash work. |
| `logo-wordmark.svg` | Horizontal lockup, 1500×400. README hero, presentations, release pages. |
| `login-logo.svg` | Greeter banner, 900×240. Installed as `/usr/share/aurora/login-logo.svg`. |
| `wallpaper.png` | Desktop and greeter background, installed as `/usr/share/aurora/wallpaper.png`. |
| `palette.md` | Color and typography reference. |

These files are the source art. The image build copies them through
`build/live-build/config/includes.chroot/usr/share/aurora/`; edit the copies
in `distribution/branding/` and keep both in sync.
